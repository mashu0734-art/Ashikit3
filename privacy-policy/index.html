Privacy Policy (Razdari Ki Policy)

📅 Aakhri Update: February 2026 • 🔒 100% Client-Side Privacy Committed

AshiKit ("hum", "hamari website") par aap ki razdari (privacy) hamari sab se ahem zimmedari hai. Yeh Privacy Policy wazahat karti hai ke jab aap hamari website (https://YOUR_DOMAIN.pages.dev) aur hamare 14 muft tools istemal karte hain, to konsi maloomat jama hoti hai aur usay kis tarah sambhala jata hai.

1. 100% Client-Side Processing Ka Ahem Asul (Zero Server Upload)

Hamari website ki sab se bari khusoosiyat yeh hai ke hamare sensitive tools mukammal tor par aap ke browser ke andar (Client-Side) run karte hain:

  • Image Tools (Image Compress, Image Resize): Jab aap koi tasveer compress ya resize karte hain to woh browser ki local HTML5 Canvas memory mein process hoti hai. Koi bhi tasveer hamare kisi server par upload nahi hoti aur na hi save hoti hai.
  • PDF Merge Tool: Multiple PDF files open-source pdf-lib JavaScript library ke zariye aap ke device ki local memory mein merge hoti hain. Files internet par transfer nahi ki jatein.
  • CV Maker: Aap ka zati data (naam, phone, tajarba) sirf aap ke samnay screen par display hota hai aur Print to PDF dabane par seedha aap ke phone/computer par save hota hai. Hamare paas aap ka koi data record nahi hota.
  • Calculators (Zakat, EMI, Age, Word Counter, Case Converter, Number Words, QR Generator): Tamam calculations foran JavaScript ke tehat aap ke device par anjam paati hain.

2. Google Input Tools API (Urdu Converter Ke Liye)

Hamara Roman Urdu to Urdu Converter tool do tarah kaam karta hai:

  • Online Mode: Yeh tool behtareen aur durust Urdu alfaz banane ke liye Google ke public Input Tools transliteration endpoint (https://inputtools.google.com/request) ko Roman Urdu lafz bhejta hai taake Google ka linguistic model durust Nastaliq lafz suggest kar sakay. Yeh sirf transliteration ke maqsad ke liye istemal hota hai.
  • Offline Fallback Mode: Agar internet connect na ho ya Google service dastiyab na ho to AshiKit ka built-in offline dictionary engine bina kisi network request ke browser mein hi conversion karta hai.

3. Cookies Aur Local Storage Ka Istemal

Hum website ke behtar tajurbay ke liye standard browser storage istemal karte hain:

  • Theme Preference (Dark Mode / Light Mode): Aap ki pasandeeda theme ko yaad rakhne ke liye localStorage.getItem('ashikit-theme') istemal hota hai.
  • Cookie Notice Status: Cookie banner ko baar baar na dikhane ke liye ashikit-cookies flag save hota hai.

4. Google AdSense Aur Third-Party Advertisements

AshiKit apne servers aur maintenance ke akhrajat poore karne ke liye Google AdSense aur deegar third-party advertising networks ke advertisements dikhata hai:

  • Third-party vendors bashamool Google, cookies istemal karte hain taake hamari ya internet ki deegar websites par aap ke pichle visits ki bunyad par munasib ads dikha sakein.
  • Google ki taraf se DoubleClick cookie ka istemal Google aur uske partners ko hamare users ko unki browsing history ki bunyad par ads dikhane ki ijazat deta hai.
  • Aap personalized advertising se kisi bhi waqt alag (opt out) ho sakte hain. Is ke liye aap Google Ads Settings par ja sakte hain.
  • Mazeed maloomat ke liye aap www.aboutads.info par ja kar third-party vendors ki cookies ko opt-out kar sakte hain.

5. Web Analytics

Hum website ki traffic aur user experience ko behtar banane ke liye privacy-friendly analytics tools (jaise Google Analytics ya Cloudflare Web Analytics) istemal kar sakte hain. Yeh tools sirf aggregate data jama karte hain jaise ke browser type, device category, page views aur mulk (country). Is mein koi bhi zaati shanakht (Personally Identifiable Information) shamil nahi hoti.

6. External Links (Doosri Websites Ke Links)

Hamari website par doosri websites (jaise Google, cdnjs, Cloudflare) ke links mojood ho sakte hain. Hum kisi bhi teesri party ki privacy policies ya unke content ke zimmedar nahi hain.

7. Bachon Ki Razdari (Children's Online Privacy)

AshiKit 13 saal se kam umar ke bachon se danista tor par koi bhi zaati maloomat jama nahi karta. Hamari service aam taleemi aur utility maqasid ke liye har umar ke afrad ke liye bilkul mehfooz hai.

8. Users Ke Huqooq (Your Data Rights)

Kyunke hum aap ka koi zaati account, passwords, credit card info ya files apne pass save nahi karte, is liye aap ka data mukammal tor par aap ke apne control mein hota hai. Aap kisi bhi waqt apne browser ki cache aur cookies clear kar ke tamam local settings ko reset kar sakte hain.

9. Policy Mein Tabdeeli (Changes to this Policy)

Hum waqt ke sath is Privacy Policy mein munasib tarameem kar sakte hain. Har nayi tabdeeli is safhay par update ki jaye gi.
